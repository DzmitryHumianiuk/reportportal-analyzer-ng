# Copy language

This product targets the global market. All user-facing copy (UI strings, mockups,
tooltips, empty states, docs meant for users) must be plain global english:

- Simple words and short sentences a QA engineer with average english understands
  on first read. No idioms, no wordplay, no rare vocabulary.
- No em-dashes or long dashes in any rendered string; no GenAI text tells.
- Name things by what the user does, not how the system is built.
